## 🧪 Testing Activities & Skills

Through these projects, I have worked with and developed practical knowledge of the following QA activities:

### 1. Manual Testing
- Understanding application requirements and business workflows.
- Identifying functional scenarios.
- Validating application behaviour against expected results.
- Performing functionality-based testing.
- Identifying potential issues and inconsistencies.

### 2. Test Case Design
- Writing structured test cases.
- Defining test scenarios and test steps.
- Identifying expected results.
- Preparing test documentation for different application modules.
- Organising test cases in Excel.

### 3. Test Execution & Documentation
- Maintaining test execution log sheets.
- Documenting testing activities.
- Recording observations and test results.
- Updating testing documentation based on requirements and feedback.

### 4. Business Workflow Analysis
- Understanding B2B operational workflows.
- Analysing application processes and user interactions.
- Organising functional requirements using mind maps.
- Understanding partner-side operational activities.
